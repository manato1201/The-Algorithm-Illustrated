## 概要

連立一次方程式 `Ax = b` を解く直接法(ガウスの消去法、LU分解)は、n×n の行列で O(n³) かかり、行列が疎(ほとんど0)でも途中で非零要素が増えて(フィルイン)、メモリを食う。偏微分方程式を格子で離散化すると、数百万変数・各行に数個しか非零がない巨大な疎行列が現れ、この方法は現実的でなくなる。

そこで、**近似解を少しずつ良くしていく反復法**が使われる。もっとも古典的なものが、ヤコビ法と、その改良版のガウス・ザイデル法である(Gauss が1823年ごろに考案、Seidel が1874年に収束の議論を与えたことにちなむ)。方程式 `i` を変数 `xᵢ` について解き直す、という素朴な操作を、全変数に順番に繰り返す。ヤコビ法は「1周前の値だけ」を使うのに対し、ガウス・ザイデル法は**更新したばかりの新しい値をすぐ後続の計算で使う**。メモリは解ベクトル1本で済み、収束もおおむねヤコビ法の2倍速い。

## 仕組み

`Ax = b` の第 `i` 式 `Σⱼ aᵢⱼ xⱼ = bᵢ` を `xᵢ` について解くと、
`xᵢ = ( bᵢ − Σ_{j≠i} aᵢⱼ xⱼ ) / aᵢᵢ`

1. 初期値 `x⁽⁰⁾` を決める(通常は全部0)
2. `k` 回目の反復で、`i = 1, 2, ..., n` の順に、
   `xᵢ⁽ᵏ⁺¹⁾ = ( bᵢ − Σ_{j<i} aᵢⱼ xⱼ⁽ᵏ⁺¹⁾ − Σ_{j>i} aᵢⱼ xⱼ⁽ᵏ⁾ ) / aᵢᵢ`
   (`j < i` は今回すでに更新した新しい値、`j > i` はまだ更新していない前回の値)
3. 解の変化量(または残差 `‖b − Ax‖`)が許容誤差より小さくなったら止める

**収束の条件**: 行列が**狭義対角優位**(各行で、対角要素の絶対値が他の要素の絶対値の和より大きい)、または対称正定値であれば、どんな初期値からでも収束する。そうでない場合は、収束しないことがある。

## 特性・トレードオフ

- **実装が簡単でメモリが小さい**: 解ベクトルをその場で上書きするだけ。行列を分解する必要がなく、疎行列の表現とも相性がよい
- **収束が遅い場合がある**: 収束の速さは行列の性質(スペクトル半径)で決まり、変数が多い問題では反復回数が増える。そのため、緩和係数を加えて速める**SOR法**、さらに前処理付きの[共役勾配法](/algorithms/conjugate-gradient-method)や、マルチグリッド法が実用では使われる
- **更新順序に依存する**: 変数を並べる順序で結果の途中経過が変わる(最終的な解は同じ)。並列化はヤコビ法ほど簡単ではない(赤黒順序づけなどの工夫がある)
- **収束しない場合がある**: 対角優位でも正定値でもない行列では発散しうる。行を入れ替えて対角を大きくするなどの前処理が要る
- **使いどころ**: 偏微分方程式の差分法の連立方程式、ラプラス方程式・ポアソン方程式の緩和、PageRankのような反復計算、マルチグリッド法の「平滑化」の部品

## 実装例

```python
def gauss_seidel(A, b, tol=1e-10, max_iter=1000):
    n = len(b)
    x = [0.0] * n
    for k in range(1, max_iter + 1):
        change = 0.0
        for i in range(n):
            s = sum(A[i][j] * x[j] for j in range(n) if j != i)   # 更新済みの x[j] もそのまま使う
            new = (b[i] - s) / A[i][i]
            change = max(change, abs(new - x[i]))
            x[i] = new
        if change < tol:
            return x, k
    return x, max_iter


A = [[10, -1, 2, 0], [-1, 11, -1, 3], [2, -1, 10, -1], [0, 3, -1, 8]]
b = [6, 25, -11, 15]
x, iterations = gauss_seidel(A, b)
print([round(v, 6) for v in x], iterations)  # 解は [1, 2, -1, 1]
```

```typescript
function gaussSeidel(
  A: number[][],
  b: number[],
  tol = 1e-10,
  maxIter = 1000,
): { x: number[]; iterations: number } {
  const n = b.length;
  const x = new Array<number>(n).fill(0);
  for (let k = 1; k <= maxIter; k++) {
    let change = 0;
    for (let i = 0; i < n; i++) {
      let s = 0;
      for (let j = 0; j < n; j++) if (j !== i) s += A[i][j] * x[j]; // 更新済みの x[j] もそのまま使う
      const next = (b[i] - s) / A[i][i];
      change = Math.max(change, Math.abs(next - x[i]));
      x[i] = next;
    }
    if (change < tol) return { x, iterations: k };
  }
  return { x, iterations: maxIter };
}

const A = [
  [10, -1, 2, 0],
  [-1, 11, -1, 3],
  [2, -1, 10, -1],
  [0, 3, -1, 8],
];
const b = [6, 25, -11, 15];
const { x, iterations } = gaussSeidel(A, b);
console.log(
  x.map((v) => Number(v.toFixed(6))),
  iterations,
); // 解は [1, 2, -1, 1]
```
