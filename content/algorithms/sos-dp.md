## 概要

n 個の要素の集合を n ビットのマスクで表し、各マスク `S` に値 `a[S]` が与えられているとする。このとき、すべての `S` について「`S` の部分集合 `T` すべてにわたる `a[T]` の合計」`f[S]` を求めたい、という問題が競技プログラミングでよく出る。「SOS(Sum Over Subsets)DP」はこれを高速に解く技法である。

素朴にやると、各 `S` の部分集合を列挙して足すので全体で 3^n 回の計算になる(各要素が「Sに含まれない・Sに含まれTにも含まれる・SにはあるがTにはない」の3通り)。SOS DPは、**ビットを1本ずつ「見る/見ない」の状態に分けて処理する**ことでこれを n · 2^n に落とす。ゼータ変換(部分集合に関する累積和)をビット単位の分割に沿って計算する、と言い換えてもよい。

## 仕組み

1. `f[S] = a[S]` で初期化する
2. ビット `i = 0, 1, ..., n-1` の順に、次を行う
   - すべてのマスク `S` について、`S` にビット `i` が立っていれば `f[S] += f[S ^ (1 << i)]`
3. すべてのビットを処理した後、`f[S]` が `S` の部分集合の総和になる

見方: ビット `i` までを処理した時点の `f[S]` は「`S` と下位 `i+1` ビット以外が同じで、下位 `i+1` ビットが `S` の部分集合になっているマスク」の合計になっている。各ビットの処理で「そのビットが立っていない版」を足すと、部分集合の範囲がそのビットまで広がる。ビットを1つ進めるごとに、足し込む範囲が1次元ずつ増えていく。

## 特性・トレードオフ

- **計算量**: O(n · 2^n)。2^20 マスクなら約2千万回で、競技では十分間に合う。メモリは 2^n 個の値
- **逆変換も同じ形**: 足す代わりに引けば(メビウス変換)、部分集合の総和から元の値を復元できる。上位集合の総和も、ビットの向きを逆にするだけで求まる
- **応用**: 「部分集合の最大・最小」「ORコンボリューション」(`f[S|T]` への畳み込みをゼータ変換→積→逆変換で計算)、包除原理の高速化、ビットDPの遷移の高速化
- **適用の条件**: 演算が結合的で、足し算に対する逆元(または冪等性)がある場合に自然に使える。最大値のように逆元がない演算でも、部分集合の最大値であれば同じループで求まる

## 実装例

```python
def subset_sum_dp(a, n):
    """a: 長さ 2^n のリスト。f[S] = sum(a[T] for T ⊆ S) を返す。"""
    f = list(a)
    for i in range(n):
        for mask in range(1 << n):
            if mask & (1 << i):
                f[mask] += f[mask ^ (1 << i)]
    return f


a = [1, 2, 3, 4, 5, 6, 7, 8]  # n = 3
print(subset_sum_dp(a, 3))  # [1, 3, 4, 10, 6, 14, 16, 36]
```

```typescript
function subsetSumDp(a: number[], n: number): number[] {
  const f = [...a];
  for (let i = 0; i < n; i++) {
    for (let mask = 0; mask < 1 << n; mask++) {
      if (mask & (1 << i)) f[mask] += f[mask ^ (1 << i)];
    }
  }
  return f;
}

console.log(subsetSumDp([1, 2, 3, 4, 5, 6, 7, 8], 3)); // [1, 3, 4, 10, 6, 14, 16, 36]
```
