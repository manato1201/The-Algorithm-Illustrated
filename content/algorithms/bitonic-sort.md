## 概要

多くの比較ソートは「いまの比較結果によって、次にどこを比べるか」が変わる。この分岐はCPUでは自然だが、数千のスレッドが同じ命令を同期して実行するGPUや、配線で作る専用回路では扱いにくい。バイトニックソート(Batcher、1968年ごろ)は、**入力の値にかかわらず比較する組が最初から決まっている**ソーティングネットワークとして設計された。分岐がないので、同じ段の比較交換を全部同時に実行できる。

名前の由来は「バイトニック列」で、先に増えてから減る(あるいはその巡回シフト)並びのこと。この形の列は、真ん中で半分に割って対応する要素同士を比べて小さい方・大きい方に振り分けるだけで、「前半は全部が後半以下になる、しかも前半も後半もまたバイトニック列」という分割が得られる。この性質を再帰的に使う。

## 仕組み

要素数 n は2のべき乗とする(そうでない場合は最大値で埋めて広げる)。

1. 長さ2のブロックを作る。隣り合う2つを比べ、ブロックごとに昇順・降順を交互に並べる。これで長さ4のバイトニック列ができる
2. **バイトニックマージ**: 長さ `k` のバイトニック列を、距離 `k/2` だけ離れた要素同士で比較交換する。昇順にしたいブロックでは小さい方を前に、降順なら大きい方を前に置く
3. 距離を `k/4, k/8, ... 1` と半分にしながら同じ操作を繰り返すと、そのブロックは指定した向きに整列する
4. ブロックの長さ `k` を 2, 4, 8, ... n と倍にしながら2〜3を繰り返す。最後の `k = n` のブロックは全体を昇順に並べる

比較交換の段数は `log n × (log n + 1) / 2`。各段で n/2 組の比較が独立に行える。

## 特性・トレードオフ

- **比較の並びがデータに依らない**: 最悪も平均も同じ回数。分岐予測やデータ依存の制御が要らず、GPUのワープや回路実装に向く
- **逐次実行では不利**: 総比較数は O(n log² n) で、ヒープソートやマージソートの O(n log n) より多い。1スレッドで動かす理由は少なく、並列度があって初めて報われる
- **要素数が2のべき乗前提**: 一般の n には、端を最大値で埋める、あるいは奇偶マージソート型のネットワークに切り替える。埋めた分だけ無駄が出る
- **安定ではない**: 同じ値の相対順序は保たれない
- **使いどころ**: GPU上のソート(ビット数の少ないキーや共有メモリ内の局所ソート)、FPGA・ASICの整列回路、SIMD命令での小さな配列のソート。大規模なGPUソートでは基数ソートが主流で、バイトニックは小さな塊の整列に使われることが多い

## 使うときの注意

並列実行では、段ごとに全スレッドの同期(バリア)が要る。段数が `log² n` あるので、n が小さいと同期のコストが計算より重くなる。

## 実装例

```python
def bitonic_sort(a):
    n = len(a)
    assert n & (n - 1) == 0, "長さは2のべき乗"
    a = list(a)
    k = 2
    while k <= n:                 # ブロックの長さ
        j = k // 2
        while j >= 1:             # 比較する距離
            for i in range(n):
                l = i ^ j         # 相手の添字
                if l > i:
                    ascending = (i & k) == 0
                    if (a[i] > a[l]) == ascending:
                        a[i], a[l] = a[l], a[i]
            j //= 2
        k *= 2
    return a


print(bitonic_sort([7, 3, 6, 1, 8, 2, 5, 4]))  # [1, 2, 3, 4, 5, 6, 7, 8]
```

```typescript
function bitonicSort(input: number[]): number[] {
  const n = input.length;
  if ((n & (n - 1)) !== 0) throw new Error("length must be a power of two");
  const a = [...input];
  for (let k = 2; k <= n; k *= 2) {
    for (let j = k / 2; j >= 1; j = Math.floor(j / 2)) {
      for (let i = 0; i < n; i++) {
        const l = i ^ j;
        if (l > i) {
          const ascending = (i & k) === 0;
          if (a[i] > a[l] === ascending) [a[i], a[l]] = [a[l], a[i]];
        }
      }
    }
  }
  return a;
}

console.log(bitonicSort([7, 3, 6, 1, 8, 2, 5, 4])); // [1, 2, 3, 4, 5, 6, 7, 8]
```
