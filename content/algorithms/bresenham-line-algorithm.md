## 概要

画面はピクセルの格子なので、斜めの線を描くには、どのピクセルを塗るかを決めなければならない。素朴には、傾き `m = Δy/Δx` を使って、x を1つ進めるごとに `y = y₀ + m(x − x₀)` を計算して四捨五入すればよい。しかし1960年代の計算機では、浮動小数点の乗算や丸めが高価で、線を引くたびに大量の乗除算をするのは、プロッタの制御に間に合わなかった。

ジャック・ブレゼンハム(Jack Bresenham)は、IBMでプロッタを制御するために、1962年にこのアルゴリズムを考案し、1965年に発表した。**直線から各ピクセル中心までのずれを「誤差」として整数で保持し、x を1つ進めるたびに、誤差が半ピクセルを超えたかどうかだけで、y を進めるかを決める**。計算は整数の加減算と符号の判定だけで済む。現在でも、グリッド上の線(ローグライクの視線、タイルベースの経路、デバッグ描画)や、ハードウェアのラスタライザの基礎として使われている。

## 仕組み

まず、`0 ≤ Δy ≤ Δx`(傾きが0〜1)の場合を考える。始点 `(x₀, y₀)`、終点 `(x₁, y₁)`、`Δx = x₁ − x₀`、`Δy = y₁ − y₀`。

1. `x` を `x₀` から `x₁` まで1ずつ進める。各 `x` で `y` は、現在の値か、その1つ上のどちらか
2. 誤差項 `D` を持つ。理想の線の `y` と、現在のピクセルの `y` の差(の2倍を整数にしたもの)で、初期値は `D = 2Δy − Δx`
3. 各ステップで、`(x, y)` を塗る。`D > 0` なら、理想の線が `y + 0.5` を超えたので、`y` を1つ進めて `D −= 2Δx` とする。そして `D += 2Δy` で、次の `x` の分の誤差を足す
4. `x = x₁` まで繰り返す

**一般の傾き**: 傾きが急(`|Δy| > |Δx|`)なら、x と y の役割を入れ替える(`y` を1ずつ進める)。`Δx` や `Δy` が負の場合は、進む向きを `±1` にする。これで8つの八分円がすべて扱える。多くの実装では、「誤差を `Δx` と `−Δy` で更新する」対称な形で、場合分けなしに書く。

## 特性・トレードオフ

- **整数のみ**: 浮動小数点も乗除算も不要。ハードウェアでも、組込み機器でも高速。丸め誤差が累積しない(誤差項が整数で厳密)
- **始点・終点を厳密に通る**: 端点が必ず塗られ、途中でも理想の線に最も近いピクセルが選ばれる(各 x/y で、誤差が半ピクセル以内)
- **線の太さ・アンチエイリアスは別問題**: 太い線や、ギザギザを滑らかにする処理(Wuの線分アルゴリズムなど)は、別の工夫が要る
- **対称性の問題**: A→B と B→A で、同じピクセルの集合になるとは限らない(誤差がちょうど0.5のとき、どちらに寄せるか)。厳密な対称性が必要なら、向きを正規化する(始点を左にそろえる)
- **円・楕円への拡張**: 同様の考え方で、中点円アルゴリズム(円)、楕円の描画が作られている
- **使いどころ**: 2Dグラフィックスの線描画、グリッド上の視線判定(レイキャスト)、タイルマップの直線経路、ゲームの弾道の判定、画像処理の線分抽出の可視化

## 実装例

```python
def bresenham(x0, y0, x1, y1):
    points = []
    dx, dy = abs(x1 - x0), -abs(y1 - y0)
    sx = 1 if x0 < x1 else -1
    sy = 1 if y0 < y1 else -1
    err = dx + dy                       # 誤差項(整数)
    while True:
        points.append((x0, y0))
        if x0 == x1 and y0 == y1:
            break
        e2 = 2 * err
        if e2 >= dy:                    # x を進める
            err += dy
            x0 += sx
        if e2 <= dx:                    # y を進める
            err += dx
            y0 += sy
    return points


print(bresenham(0, 0, 10, 4))
# [(0, 0), (1, 0), (2, 1), (3, 1), (4, 2), (5, 2), (6, 2), (7, 3), (8, 3), (9, 4), (10, 4)](x ごとに y は 0 か 1 だけ進む)
print(bresenham(2, 7, 0, 0))   # 急な傾きでも、向きが逆でも同じ関数で描ける
```

```typescript
function bresenham(
  x0: number,
  y0: number,
  x1: number,
  y1: number,
): [number, number][] {
  const points: [number, number][] = [];
  const dx = Math.abs(x1 - x0);
  const dy = -Math.abs(y1 - y0);
  const sx = x0 < x1 ? 1 : -1;
  const sy = y0 < y1 ? 1 : -1;
  let err = dx + dy;
  for (;;) {
    points.push([x0, y0]);
    if (x0 === x1 && y0 === y1) break;
    const e2 = 2 * err;
    if (e2 >= dy) {
      err += dy;
      x0 += sx;
    }
    if (e2 <= dx) {
      err += dx;
      y0 += sy;
    }
  }
  return points;
}

console.log(
  bresenham(0, 0, 10, 4)
    .map(([x, y]) => `(${x},${y})`)
    .join(" "),
);
console.log(
  bresenham(2, 7, 0, 0)
    .map(([x, y]) => `(${x},${y})`)
    .join(" "),
);
```
