## 概要

弦をはじいた瞬間、弦には様々な周波数成分を含む複雑な振動(ノイズ的な励起)が発生し、それが弦の両端で反射を繰り返しながら徐々にエネルギーを失っていく——これが撥弦楽器(ギター、ハープ、ピアノの打弦なども近い)の音が鳴る物理過程である。Karplus-Strongアルゴリズムは、この過程を「短いランダム信号で満たした**遅延バッファ(リングバッファ)**をループ再生しながら、通過するたびに簡単なローパスフィルタで少しずつ減衰させる」という驚くほど単純な仕組みで模倣する。1983年にKevin KarplusとAlex Strongによって考案され、[フォルマント合成](/algorithms/formant-synthesis)のような音源-フィルタモデルとは異なり物理的な弦の振動そのものを直接シミュレートする点が特徴で、物理モデリング音源(Physical Modeling Synthesis)の最も基礎的で有名な例として知られる。計算量が極めて小さいため、初期のデジタルシンセサイザーやゲーム機の音源チップでも実用的に使われてきた。

## 仕組み

1. **遅延バッファの初期化**: 長さ`N`(生成したいピッチの1周期分のサンプル数、`N = sample_rate / frequency`)のバッファを、`-1`から`1`の範囲の**乱数(白色雑音)**で満たす。この初期状態が「弦をはじいた瞬間」の複雑な振動を表す
2. **読み出しと同時に減衰・書き戻し**: バッファの先頭から順にサンプルを1つずつ出力しながら、次の処理を行う
   - 出力するサンプル`buf[i]`と、直後のサンプル`buf[(i+1) % N]`を平均する: `avg = (buf[i] + buf[(i+1) % N]) / 2`
   - 平均値に減衰係数`decay`(通常0.98〜0.999程度)を掛けたものを、読み出した位置に書き戻す: `buf[i] = decay * avg`
   - このステップが**2点移動平均によるローパスフィルタ**として働き、高周波成分ほど早く減衰する(弦の高次倍音が低次倍音より速く消えていく実際の物理現象と一致する)
3. インデックス`i`をバッファ長`N`で循環させながら1と2を繰り返し、望むサンプル数だけ出力する
4. バッファ長`N`がそのまま基本周期(ピッチ)を決めるため、`N`を変えるだけで異なる音高を生成できる。整数でない周期が必要な場合は線形補間で分数長を近似する

減衰の平均化フィルタは周波数領域で見ると`H(z) = decay・(1 + z^-1)/2`という1次ローパスフィルタに相当し、ナイキスト周波数付近の成分ほど強く減衰させる。これにより単に振幅全体を小さくする(すべての倍音を均等に減衰させる)のではなく、実際の弦のように高い倍音から先に消えていく自然な音色変化が得られる。

## 特性・トレードオフ

- **極めて低い計算コスト**: 1サンプルあたり加算・乗算数回のみで、フォルマント合成のような複数の共振フィルタも、複雑な波形テーブルも必要としない。組み込み機器や初期のゲーム機のような計算資源が乏しい環境でも実用的に弦楽器音を生成できた
- **物理的にもっともらしい減衰特性**: 移動平均フィルタが高周波を優先的に減衰させるため、明示的に倍音構成をプログラムしなくても「はじいた直後は明るく、時間とともにこもった音になる」という弦楽器らしい音色変化が自然に得られる。これは加算合成やウェーブテーブル音源では倍音ごとに個別のエンベロープを設計しないと得にくい特性である
- **減衰係数とピッチの相互作用**: 減衰係数`decay`が1に近いほど音が長く伸び、小さいほど短く減衰する。ただし`decay`を大きくしすぎる(1以上にする)と発振して音量が発散するため、安定した減衰のためには`decay < 1`を保つ必要がある。バッファ長`N`が短いほど(高音になるほど)フィルタが1周期あたりに通過する回数が増えるため、同じ`decay`値でも高音ほど早く減衰して聞こえる
- **音色の拡張(Extended Karplus-Strong)**: 単純な平均化フィルタの代わりにより複雑なローパスフィルタを使ったり、励起信号にノイズ以外の波形(のこぎり波など)を混ぜたり、ピッキング位置をシミュレートするコムフィルタを追加するなど、基本アルゴリズムに手を加えることで金属的な音・打楽器的な音など表現の幅を広げられる
- **使いどころ**: ギター・ハープ・琴などの撥弦楽器のリアルタイム音源、チップチューン/レトロゲームサウンド、計算資源が限られる組み込みオーディオ、物理モデリングシンセサイザーの入門的な実装

## 実装例

```python
import random

def karplus_strong(
    frequency: float, duration: float, sample_rate: int = 44100, decay: float = 0.996,
) -> list[float]:
    n = max(2, round(sample_rate / frequency))
    # 遅延バッファを白色雑音で初期化(弦をはじいた瞬間の励起)
    buf = [random.uniform(-1.0, 1.0) for _ in range(n)]

    total_samples = int(sample_rate * duration)
    output = []
    i = 0
    for _ in range(total_samples):
        current = buf[i]
        nxt = buf[(i + 1) % n]
        # 2点移動平均によるローパスフィルタ + 減衰
        buf[i] = decay * 0.5 * (current + nxt)
        output.append(current)
        i = (i + 1) % n
    return output
```

```typescript
function karplusStrong(
  frequency: number,
  duration: number,
  sampleRate = 44100,
  decay = 0.996,
): Float64Array {
  const n = Math.max(2, Math.round(sampleRate / frequency));
  // 遅延バッファを白色雑音で初期化(弦をはじいた瞬間の励起)
  const buf = new Float64Array(n);
  for (let k = 0; k < n; k++) buf[k] = Math.random() * 2 - 1;

  const totalSamples = Math.floor(sampleRate * duration);
  const output = new Float64Array(totalSamples);
  let i = 0;
  for (let s = 0; s < totalSamples; s++) {
    const current = buf[i];
    const next = buf[(i + 1) % n];
    // 2点移動平均によるローパスフィルタ + 減衰
    buf[i] = decay * 0.5 * (current + next);
    output[s] = current;
    i = (i + 1) % n;
  }
  return output;
}
```
