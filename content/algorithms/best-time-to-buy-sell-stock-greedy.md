## 概要

日々の株価が並んだ配列が与えられたとき、「1回だけ買って、その後1回だけ売る」ことで得られる**最大の利益**を求めたい、という問題。全ての(買う日, 売る日)の組み合わせを総当たりで調べればO(n²)かかるが、「これまでに見た中で最も安かった価格」だけを1つの変数で追跡しながら配列を1回走査するだけで、O(n)で最適解が求まる。[カダンのアルゴリズム](/algorithms/kadane)と同様に、局所的な情報の更新だけで大域的な最適値に到達する、貪欲法の考え方がきれいに現れる入門的な問題。

## 仕組み

1. 「これまでに見た中での最小価格」を最初の日の価格で初期化し、「これまでの最大利益」を0で初期化する
2. 2日目以降の価格を順に見ていき、各日について**「今日売った場合の利益」= 今日の価格 - これまでの最小価格**を計算する
3. この利益が、これまでの最大利益より大きければ、最大利益を更新する
4. 今日の価格が、これまでの最小価格より小さければ、最小価格を更新する
5. 配列の末尾まで2〜4を繰り返せば、最大利益の変数が答えになる

**貪欲法としての本質**: 各日について「もし今日売るなら、これまでの最安値で買っておくのが最善」という局所的な判断だけを行い、将来の価格がどうなるかは一切先読みしない。それでも「これまでの最小値」という1つの統計量を正しく引き継いでいくことで、結果的に全区間の中から真に最大の利益を出す(買う日, 売る日)の組が見つかる。

## 特性・トレードオフ

- **計算量**: O(n)、追加メモリはO(1)。全ての(買う日, 売る日)の組をO(n²)で総当たりする素朴な方法に比べ、1回の走査で済む
- **貪欲法が"証明付きで"最適になる理由**: 「今日売るなら、これまでの最小価格で買うのが最善」という主張は自明ではないように見えるが、実は「売る日を固定すれば、それより前の日で最も安い日に買うのが最適」という単純な事実の言い換えに過ぎない。全ての売る日について、その時点までの最小購入価格との差分を調べ尽くしているため、これは貪欲法でありながら実質的に全探索と同じ答えに到達することが保証されている——[区間スケジューリング問題](/algorithms/interval-scheduling)と同じく、貪欲法の正しさを厳密に証明できる稀有な例
- **「複数回取引可能」版との違い**: 本問題は「1回だけ売買できる」という制約下での貪欲法だが、「何度でも売買してよい(ただし同時に複数株は持てない)」という設定に変わると話が変わる。この場合は「価格が上がった区間の差分を全て合計する」という別の貪欲規則が最適になり、両者を混同すると誤った実装をしやすい点に注意
- **反例(単純な"上がったら買う"戦略が失敗するケース)**: 価格が`[7, 1, 5, 3, 6, 4]`と推移する場合、「前日より上がっていたら昨日買って今日売る」という近視眼的な貪欲を1回の取引に単純適用すると`1→5`(差4)や`3→6`(差3)を局所的に捉えられても、それらを跨いだ真の最大差である`1(2日目)→6(5日目)`の差5を見逃しうる。「これまでの最小値」というグローバルな統計量を正しく引き継ぐ設計になっていなければ、貪欲法は容易に局所最適に落ち込む
- **使いどころ**: 金融データにおける最大利益区間の探索そのものに加え、「配列内の2要素の差の最大値を求める」という抽象化により、温度センサーのデータから最大の変化幅を探す、時系列データの異常な上昇区間を検出するなど、幅広い差分最大化問題に応用できる

## 実装例

```python
def max_profit(prices: list[int]) -> int:
    if not prices:
        return 0
    min_price = prices[0]
    best_profit = 0
    for price in prices[1:]:
        profit = price - min_price
        if profit > best_profit:
            best_profit = profit
        if price < min_price:
            min_price = price
    return best_profit
```

```typescript
function maxProfit(prices: number[]): number {
  if (prices.length === 0) return 0;
  let minPrice = prices[0];
  let bestProfit = 0;
  for (let i = 1; i < prices.length; i++) {
    const profit = prices[i] - minPrice;
    if (profit > bestProfit) bestProfit = profit;
    if (prices[i] < minPrice) minPrice = prices[i];
  }
  return bestProfit;
}
```
