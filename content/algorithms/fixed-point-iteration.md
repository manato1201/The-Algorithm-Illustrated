## 概要

方程式`f(x) = 0`を解く方法は数多くあるが、その多くは実は「同じアイデアの特殊ケース」として理解できる。不動点反復法は、方程式`f(x) = 0`を**同値な形**`x = g(x)`に書き換え(`g`の選び方は一通りではない)、適当な初期値`x₀`から出発して`x_{n+1} = g(x_n)`という反復を繰り返すだけで、`g`の**不動点**(`g(x*) = x*`を満たす点`x*`、これは元の方程式`f(x*) = 0`の解でもある)に収束させる、求根アルゴリズムの最も基礎的で一般的な枠組みである。[ニュートン法](/algorithms/newton-method)や[割線法](/algorithms/secant-method)は、実はこの不動点反復法において`g(x)`を特別に選んだ(接線・割線の交点を使う)特殊ケースにすぎない、という見方ができる。

## 仕組み

1. 解きたい方程式`f(x) = 0`を、`x = g(x)`という形に変形する。同じ`f(x) = 0`でも`g(x)`の選び方は複数ありうる(例: `f(x) = x² - x - 2 = 0`は`x = x² - 2`とも`x = √(x + 2)`とも`x = 2/(x - 1)`とも変形できる)
2. 初期推定値`x₀`を選ぶ
3. `x_{n+1} = g(x_n)`を計算する(`g`を1回評価するだけの単純な操作)
4. `|x_{n+1} - x_n|`が十分小さくなる(収束した)まで、3を繰り返す。数列`x₀, x₁, x₂, ...`が収束すればその極限`x*`は`x* = g(x*)`を満たす不動点であり、`f(x*) = 0`の解になっている
5. **収束するかどうかは`g`の選び方に強く依存する**。不動点`x*`の近くで`|g'(x*)| < 1`が成り立てば局所的に収束することが縮小写像の原理(バナッハの不動点定理)から保証されるが、`|g'(x*)| > 1`だと同じ`x*`が数学的には不動点であっても、反復は`x*`から遠ざかるように発散してしまう。同じ方程式でも`g`の選び方次第で収束したりしなかったりする、というのがこの手法の最大の特徴である

## 特性・トレードオフ

- **ニュートン法は特別な不動点反復とみなせる**: [ニュートン法](/algorithms/newton-method)の更新式`x_{n+1} = x_n - f(x_n)/f'(x_n)`は、`g(x) = x - f(x)/f'(x)`と置いた不動点反復に他ならない。この`g`を微分すると不動点`x*`(`f(x*)=0`)の近くで`g'(x*) = 0`となることが分かり、これが[ニュートン法](/algorithms/newton-method)が2次収束する(単なる線形収束より遥かに速い)理由を、不動点反復の枠組みから説明できる
- **収束条件`|g'(x)| < 1`が本質**: 不動点`x*`の近傍で`g`の傾きの絶対値が1未満であれば、反復のたびに`x*`との誤差がその傾きの倍率で縮んでいくため収束する(1次収束、収束の速さは`|g'(x*)|`が0に近いほど速い)。逆に`|g'(x*)| > 1`だと誤差が反復のたびに拡大し発散する。同じ根を持つ方程式でも`g`の変形の仕方次第で収束・発散が分かれるため、実際に使う際は`g'(x)`を確認するか、複数の変形を試す必要がある
- **[二分法](/algorithms/bisection-method)のような「必ず収束する」保証はない**: 不動点反復は`g`の選び方が悪いと簡単に発散する。収束を保証したい場面では[二分法](/algorithms/bisection-method)のような区間を絞り込む手法の方が頑健であり、不動点反復は「うまく`g`を選べれば単純な反復だけで速く解ける」という実装の単純さと引き換えに、収束の保証を犠牲にしている
- **反復法・機械学習との接続**: `x_{n+1} = g(x_n)`という反復更新の形は、[勾配降下法](/algorithms/gradient-descent)(`g(x) = x - η∇f(x)`と見なせる)やPageRankのべき乗法など、数値計算・機械学習・グラフアルゴリズムに現れる多くの反復更新則の共通の骨格になっている。不動点反復の収束理論は、これら派生アルゴリズムの収束性を理解する土台にもなる
- **使いどころ**: `x = g(x)`の形に素直に変形できる方程式の求根、[ニュートン法](/algorithms/newton-method)や[割線法](/algorithms/secant-method)がなぜ・どのように収束するかを理解するための統一的な視点、経済学の均衡点計算や機械学習の反復更新則など「反復すれば安定点に落ち着く」現象全般の数学的基礎

## 実装例(f(x) = x² - x - 2 = 0 の正の解 x = 2 を、g(x) = √(x + 2) を使って求める)

```python
from typing import Callable


def fixed_point_iteration(
    g: Callable[[float], float],
    x0: float,
    tol: float = 1e-10,
    max_iter: int = 200,
) -> float:
    x = x0
    for _ in range(max_iter):
        x_next = g(x)
        if abs(x_next - x) < tol:
            return x_next
        x = x_next
    return x


# f(x) = x^2 - x - 2 = 0 を x = sqrt(x + 2) の形に変形(この g は解 x=2 近傍で |g'(x)| < 1 なので収束する)
root = fixed_point_iteration(lambda x: (x + 2) ** 0.5, x0=1.0)
print(root)  # -> 2.0 に収束

# 悪い変形の例: x = x^2 - 2 は g'(2) = 4 で |g'(x*)| > 1 のため、
# 同じ解 x=2 を不動点に持つにもかかわらず初期値次第で発散する
diverging_g: Callable[[float], float] = lambda x: x**2 - 2
```

```typescript
function fixedPointIteration(
  g: (x: number) => number,
  x0: number,
  tol: number = 1e-10,
  maxIter: number = 200,
): number {
  let x = x0;
  for (let i = 0; i < maxIter; i++) {
    const xNext = g(x);
    if (Math.abs(xNext - x) < tol) return xNext;
    x = xNext;
  }
  return x;
}

// f(x) = x^2 - x - 2 = 0 を x = sqrt(x + 2) の形に変形(この g は解 x=2 近傍で |g'(x)| < 1 なので収束する)
const root = fixedPointIteration((x) => Math.sqrt(x + 2), 1.0);
console.log(root); // -> 2.0 に収束

// 悪い変形の例: x = x^2 - 2 は g'(2) = 4 で |g'(x*)| > 1 のため、
// 同じ解 x=2 を不動点に持つにもかかわらず初期値次第で発散する
const divergingG = (x: number): number => x ** 2 - 2;
```
