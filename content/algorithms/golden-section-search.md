---
name: 黄金分割探索(Golden Section Search)
category: 探索
subcategory: 配列探索
complexity: O(log(1/ε))
summary: 単峰関数の極値を、区間を黄金比で分割しながら評価回数を最小限に抑えて絞り込む数値探索法。
---

## 概要

二分探索が「ソート済み配列から値を探す」手法であるのに対し、黄金分割探索は「単峰(unimodal)な連続関数の最大値・最小値を探す」ための探索法である。関数の微分が使えない、あるいは微分不可能な状況でも、関数値の大小比較だけで最適点に絞り込める。1953年にJack Kieferが考案した手法で、区間を黄金比 φ = (√5 - 1)/2 ≈ 0.618 で分割することで、**毎回の反復で新しく評価する点を1つだけに抑えつつ**区間を一定の比率で縮小できるという効率性が名前の由来になっている。

## 仕組み

1. 極値が存在するとわかっている区間 [a, b] を用意する(単峰性が前提)
2. 区間内に黄金比に基づく2つの内点 c, d を置く(c = b - φ(b-a)、d = a + φ(b-a))
3. f(c) と f(d) を比較する。最小値を探す場合、値が小さい方を含む側に区間を絞り込む
   - f(c) < f(d) なら、極値は [a, d] の中にあるので b を d に更新
   - そうでなければ、極値は [c, b] の中にあるので a を c に更新
4. **黄金比の性質により、更新後の区間に残る内点(cまたはd)を再利用でき、新たに関数を評価する点は1つだけで済む**
5. 区間の幅が許容誤差ε未満になるまで2〜4を繰り返す
6. 最終的な区間の中点(または端点の平均)を極値の近似解として返す

## 特性・トレードオフ

- **計算量**: 区間の縮小率が毎回φ(≈0.618倍)なので、目的の精度εに到達するまでの反復回数はO(log(1/ε))。関数評価の回数を最小化する点で理論的に最適な分割比率であることが証明されている
- **微分不要**: 勾配法(ニュートン法など)と異なり導関数が不要。関数がブラックボックス(シミュレーション結果など)でも適用できる
- **単峰性が前提条件**: 対象の区間内に極値が1つしかない(単峰)ことが必須。多峰関数には全体探索や分割統治との組み合わせが必要
- **三分探索との違い**: 三分探索は毎回2点を新たに評価するのに対し、黄金分割探索は前回評価した点を再利用するため関数評価の回数が少なく済む。関数評価が高コスト(重いシミュレーションなど)な場面で特に有利
- **使いどころ**: ハイパーパラメータの1次元チューニング、ポートフォリオ最適化のような単峰なコスト関数の最小化、ライン探索(勾配法内部でのステップ幅決定)

## 実装例

```python
import math

def golden_section_search(f, a: float, b: float, tol: float = 1e-8) -> float:
    """[a, b] 上の単峰関数 f の最小値を与える x を返す"""
    invphi = (math.sqrt(5) - 1) / 2  # 1/φ ≈ 0.618

    c = b - invphi * (b - a)
    d = a + invphi * (b - a)
    fc, fd = f(c), f(d)

    while abs(b - a) > tol:
        if fc < fd:
            b, d, fd = d, c, fc
            c = b - invphi * (b - a)
            fc = f(c)
        else:
            a, c, fc = c, d, fd
            d = a + invphi * (b - a)
            fd = f(d)

    return (a + b) / 2
```

```typescript
function goldenSectionSearch(
  f: (x: number) => number,
  a: number,
  b: number,
  tol = 1e-8,
): number {
  const invphi = (Math.sqrt(5) - 1) / 2; // 1/φ ≈ 0.618

  let c = b - invphi * (b - a);
  let d = a + invphi * (b - a);
  let fc = f(c);
  let fd = f(d);

  while (Math.abs(b - a) > tol) {
    if (fc < fd) {
      b = d;
      d = c;
      fd = fc;
      c = b - invphi * (b - a);
      fc = f(c);
    } else {
      a = c;
      c = d;
      fc = fd;
      d = a + invphi * (b - a);
      fd = f(d);
    }
  }

  return (a + b) / 2;
}
```
