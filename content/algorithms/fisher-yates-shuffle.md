## 概要

トランプのシャッフルやゲーム内のルーレット報酬の抽選順など、「配列の要素の並びをランダムにする」処理は一見単純に思えるが、素朴な実装(各要素をランダムな位置と交換する、といった直感的な方法)では実は**特定の並びが他より出やすくなる偏り**が生じてしまうことがよくある。Fisher-Yatesシャッフル(Ronald FisherとFrank Yatesが1938年に考案し、後にDurstenfeldが計算機向けにO(n)の効率的な形に改良した)は、配列を後ろから順に走査しながら、各位置の要素を「まだ確定していない範囲」からランダムに選んだ要素と交換していく手続きで、n個の要素のn!通りの並び替えが**厳密に等確率**で生成されることが数学的に証明されているアルゴリズムである。追加のメモリを使わずO(n)で完了する効率性と、偏りのなさが数学的に保証されている点から、乱数を扱うあらゆるソフトウェアで標準的に使われるシャッフル手法になっている。

## 仕組み

配列`a[0..n-1]`をシャッフルする手順(Durstenfeldによる現代的な実装、後ろから前へ走査する版):

1. `i`を`n-1`から`1`まで、1ずつ減らしながら繰り返す
2. 各`i`について、`0`以上`i`以下の範囲から一様ランダムに整数`j`を選ぶ
3. `a[i]`と`a[j]`を交換する(`i`自身が選ばれた場合、つまり`j == i`の場合は実質的に何もしない)
4. `i`が`1`になった時点で終了する(`i=0`の要素は交換相手の範囲が自分自身しかないため処理不要)

**なぜ全順列が等確率になるのか**: この手続きは「まだ確定していない範囲`[0, i]`から、位置`i`に入る要素を選ぶ」という操作を`i = n-1, n-2, ..., 1`の順に繰り返しているとみなせる。位置`n-1`に入る要素はn通りの候補から等確率で1つ選ばれ(確率`1/n`)、次に位置`n-2`に入る要素は残りの`n-1`通りから等確率で選ばれ(確率`1/(n-1)`)、という具合に各位置の選択が独立に一様である。これらの確率を全て掛け合わせると`1/n × 1/(n-1) × ... × 1/1 = 1/n!`となり、n!通りの並びのどれもが厳密に同じ確率`1/n!`で生成されることが分かる。

対して、よくある誤った実装(**"シャッフル・シャッフル"バグ**とも呼ばれる)である「各`i`について`0`以上`n-1`以下(確定していない範囲に限定せず全範囲)からランダムに`j`を選んで交換する」という方法は、生成される順列の確率分布が一様にならず、特定の並びが他より`O(n^n / n!)`倍近く出やすくなるという偏りを生む。

## 特性・トレードオフ

- **計算量**: O(n)時間・O(1)の追加メモリ(配列内で交換するだけ)で完了し、n!通りの全順列が数学的に厳密な一様分布で得られる
- **乱数生成器の品質への依存**: シャッフルの公平性そのものは証明されているが、実際の偏りのなさは使用する乱数生成器の質に依存する。範囲`[0, i]`の一様な整数を得る際、`rand() % (i+1)`のような単純な剰余演算は、`rand()`の出力範囲が`(i+1)`で割り切れない場合にわずかな偏り(モジュロバイアス)を生むため、範囲指定の一様乱数を正しく生成する処理(棄却法など)が必要になる。[XorShift法](/algorithms/xorshift)や[Xoshiro256**乱数生成法](/algorithms/xoshiro256)のような統計的品質の高い乱数源と組み合わせるのが望ましい
- **大きな`n!`の壁**: `n`が大きくなると`n!`通りの並びを表現するのに必要な状態数(エントロピー)は乱数生成器の周期を上回ってしまう(例えば52枚のトランプは`52!`通り以上の並びがあり、これは多くの32bit・64bit乱数生成器の周期よりずっと大きい)。理論上は全ての並びに到達できない場合があるが、実用上ゲームやシミュレーションで問題になることは稀
- **[Reservoir Sampling](/algorithms/reservoir-sampling)との関係**: どちらも「一様ランダムな選択」を保証する古典的な乱数アルゴリズムだが、Reservoir Samplingは「サイズが未知・巨大なストリームからk個を一様に抽出する」問題を解くのに対し、Fisher-Yatesシャッフルは「既知のn個の要素の並びを一様にランダム化する」問題を解く
- **使いどころ**: トランプ・カードゲームのデッキシャッフル、ゲーム内の抽選順序やドロップ順のランダム化、[ピティシステム](/algorithms/pity-system)と組み合わせたガチャの排出順管理、テストデータのランダム順シャッフル、機械学習でのデータセットのシャッフル

## 実装例

```python
import random


def fisher_yates_shuffle(arr: list, rng: random.Random | None = None) -> list:
    """arrをその場でシャッフルし、同じリストを返す(元の配列は破壊的に変更される)"""
    r = rng if rng is not None else random
    result = arr  # 呼び出し側でコピーを渡すことを想定
    for i in range(len(result) - 1, 0, -1):
        j = r.randint(0, i)  # [0, i] を含む一様乱数
        result[i], result[j] = result[j], result[i]
    return result


def fisher_yates_shuffled_copy(arr: list, rng: random.Random | None = None) -> list:
    """元の配列を変更せず、シャッフル済みの新しいリストを返す"""
    return fisher_yates_shuffle(list(arr), rng)


if __name__ == "__main__":
    deck = list(range(52))
    rng = random.Random(42)
    shuffled = fisher_yates_shuffled_copy(deck, rng)
    print(shuffled)
```

```typescript
function fisherYatesShuffle<T>(
  arr: T[],
  rand: () => number = Math.random,
): T[] {
  // arrをその場でシャッフルし、同じ配列を返す(破壊的)
  for (let i = arr.length - 1; i > 0; i--) {
    const j = Math.floor(rand() * (i + 1)); // [0, i] の一様な整数
    [arr[i], arr[j]] = [arr[j], arr[i]];
  }
  return arr;
}

function fisherYatesShuffledCopy<T>(
  arr: T[],
  rand: () => number = Math.random,
): T[] {
  // 元の配列を変更せず、シャッフル済みの新しい配列を返す
  return fisherYatesShuffle([...arr], rand);
}

// 使用例: 52枚のトランプをシャッフル
const deck = Array.from({ length: 52 }, (_, i) => i);
const shuffled = fisherYatesShuffledCopy(deck);
console.log(shuffled);
```
