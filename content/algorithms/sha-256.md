## 概要

データの完全性の確認や電子署名には、「データを短い値に写し、同じ値になる別のデータを作れない」ことが保証された関数が要る。MD5やSHA-1は設計の弱点が見つかり、衝突(同じハッシュ値になる2つの異なる入力)が実際に作れることが示されて、新規の用途には使われなくなった。

SHA-256は、米国のNIST(国立標準技術研究所)が2001〜2002年ごろにSHA-2ファミリーの一員としてFIPS 180-2で標準化したハッシュ関数(設計は米国家安全保障局による)である。Gitのオブジェクト識別子(移行中)、TLS証明書の署名、ビットコインのマイニング(二重SHA-256)、パスワード派生関数の部品など、現代のセキュリティの土台として広く使われている。

## 仕組み

メルクル・ダムゴー構成(ブロックを順に圧縮して、状態を引き継ぐ)の一種。

1. **パディング**: メッセージの末尾にビット `1` を付け、`0` で埋めて、最後に元の長さ(ビット単位・64ビット)を置く。全体の長さを512ビット(64バイト)の倍数にする
2. **初期値**: 8個の32ビット語 `H0..H7` を、最初の8個の素数の平方根の小数部から決めた定数で初期化する(「怪しい定数を埋め込んでいない」ことの説明になっている)
3. **各ブロックの処理**:
   - 16語のブロックから、64語のメッセージスケジュール `W[0..63]` を作る。`W[t] = σ1(W[t−2]) + W[t−7] + σ0(W[t−15]) + W[t−16]`(σは回転とシフトとXORの組み合わせ)
   - 作業変数 `a..h` に現在の状態を入れ、64ラウンド繰り返す。各ラウンドで `Ch`(選択)・`Maj`(多数決)・`Σ0`・`Σ1` という論理関数と、ラウンド定数 `K[t]`(最初の64個の素数の立方根の小数部)を使って `a..h` を更新する
   - 計算後の `a..h` を現在の状態 `H0..H7` に足し込む(Davies–Meyer型)
4. 全ブロックの処理後、`H0..H7` を連結した256ビットが出力

## 特性・トレードオフ

- **安全性の性質**: 原像耐性・第2原像耐性・衝突耐性。256ビット出力なので、衝突を見つける総当たりの目安は 2^128 回(誕生日攻撃)。現時点でSHA-256の衝突や原像を現実的に作る方法は知られていない
- **長さ拡張攻撃を受ける**: ハッシュ値 `H(m)` と `m` の長さが分かれば、`m` を知らなくても `H(m ‖ padding ‖ 追加データ)` が計算できる。そのため `H(秘密 ‖ メッセージ)` を認証コードにしてはならず、HMACを使う(あるいはSHA-512/256やSHA-3のように、内部状態の一部しか出力しない関数を選ぶ)
- **パスワードの保存には単独で使わない**: 高速すぎるため、GPUで秒間数十億回の総当たりが可能。鍵伸長(PBKDF2・scrypt・Argon2など)と、ソルトを併用する
- **速度**: 逐次処理で並列化しにくい(1ブロックの結果が次に必要)。CPUにSHA拡張命令がある環境では非常に速い
- **使いどころ**: ファイルの整合性検査、デジタル署名の前処理、メルクル木、コミットメント、ブロックチェーンのブロックハッシュ

def rotr(x, n):
    return ((x >> n) | (x << (32 - n))) & 0xFFFFFFFF


def sha256(message: bytes) -> str:
    h = [0x6A09E667, 0xBB67AE85, 0x3C6EF372, 0xA54FF53A, 0x510E527F, 0x9B05688C, 0x1F83D9AB, 0x5BE0CD19]
    padded = message + b"\x80"
    padded += b"\x00" * ((56 - len(padded) % 64) % 64)
    padded += struct.pack(">Q", len(message) * 8)
    for offset in range(0, len(padded), 64):
        w = list(struct.unpack(">16I", padded[offset:offset + 64])) + [0] * 48
        for t in range(16, 64):
            s0 = rotr(w[t - 15], 7) ^ rotr(w[t - 15], 18) ^ (w[t - 15] >> 3)
            s1 = rotr(w[t - 2], 17) ^ rotr(w[t - 2], 19) ^ (w[t - 2] >> 10)
            w[t] = (w[t - 16] + s0 + w[t - 7] + s1) & 0xFFFFFFFF
        a, b, c, d, e, f, g, hh = h
        for t in range(64):
            big1 = rotr(e, 6) ^ rotr(e, 11) ^ rotr(e, 25)
            ch = (e & f) ^ (~e & g)
            t1 = (hh + big1 + ch + K[t] + w[t]) & 0xFFFFFFFF
            big0 = rotr(a, 2) ^ rotr(a, 13) ^ rotr(a, 22)
            maj = (a & b) ^ (a & c) ^ (b & c)
            t2 = (big0 + maj) & 0xFFFFFFFF
            hh, g, f, e, d, c, b, a = g, f, e, (d + t1) & 0xFFFFFFFF, c, b, a, (t1 + t2) & 0xFFFFFFFF
        h = [(x + y) & 0xFFFFFFFF for x, y in zip(h, [a, b, c, d, e, f, g, hh])]
    return "".join(f"{x:08x}" for x in h)


print(sha256(b"abc"))

const rotr = (x: number, n: number): number => (x >>> n) | (x << (32 - n));

function sha256(message: Uint8Array): string {
  const h = new Uint32Array([
    0x6a09e667, 0xbb67ae85, 0x3c6ef372, 0xa54ff53a, 0x510e527f, 0x9b05688c,
    0x1f83d9ab, 0x5be0cd19,
  ]);
  const padLength = ((message.length + 9 + 63) >> 6) << 6;
  const padded = new Uint8Array(padLength);
  padded.set(message);
  padded[message.length] = 0x80;
  const view = new DataView(padded.buffer);
  view.setUint32(padLength - 8, Math.floor((message.length * 8) / 2 ** 32));
  view.setUint32(padLength - 4, (message.length * 8) >>> 0);
  const w = new Uint32Array(64);
  for (let offset = 0; offset < padLength; offset += 64) {
    for (let t = 0; t < 16; t++) w[t] = view.getUint32(offset + t * 4);
    for (let t = 16; t < 64; t++) {
      const s0 = rotr(w[t - 15], 7) ^ rotr(w[t - 15], 18) ^ (w[t - 15] >>> 3);
      const s1 = rotr(w[t - 2], 17) ^ rotr(w[t - 2], 19) ^ (w[t - 2] >>> 10);
      w[t] = (w[t - 16] + s0 + w[t - 7] + s1) >>> 0;
    }
    let [a, b, c, d, e, f, g, hh] = h;
    for (let t = 0; t < 64; t++) {
      const big1 = rotr(e, 6) ^ rotr(e, 11) ^ rotr(e, 25);
      const ch = (e & f) ^ (~e & g);
      const t1 = (hh + big1 + ch + K[t] + w[t]) >>> 0;
      const big0 = rotr(a, 2) ^ rotr(a, 13) ^ rotr(a, 22);
      const maj = (a & b) ^ (a & c) ^ (b & c);
      const t2 = (big0 + maj) >>> 0;
      hh = g;
      g = f;
      f = e;
      e = (d + t1) >>> 0;
      d = c;
      c = b;
      b = a;
      a = (t1 + t2) >>> 0;
    }
    [a, b, c, d, e, f, g, hh].forEach((v, i) => (h[i] = (h[i] + v) >>> 0));
  }
  return [...h].map((x) => x.toString(16).padStart(8, "0")).join("");
}
