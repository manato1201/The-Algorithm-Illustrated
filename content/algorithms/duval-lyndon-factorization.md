## 概要

文字列が**リンドン語**であるとは、自分自身が、自分のどの真の接尾辞よりも辞書順で小さいこと(`ab`、`aab`、`abb` など)。リンドンの定理(Chen–Fox–Lyndon)により、あらゆる文字列は、リンドン語を辞書順で**弱い意味で降順(同じものは並んでよい)**に並べた列にただ1通りに分解できる。これがリンドン分解である。

分解自体は面白い数学的事実だが、実用性は「**文字列の最小の巡回シフトを求める**」「接尾辞配列・BWTの構築」「組合せ論的な文字列の列挙」などにある。デュヴァル(Jean-Pierre Duval、1983年)は、この分解を**線形時間・補助メモリ O(1)** で求める簡潔な方法を示した。

## 仕組み

3つの添字 `i`(今の塊の先頭)、`j`、`k` を持つ。区間 `[i, j)` は「リンドン語の繰り返し+その接頭辞」になっていると仮定して走査する。

1. `j = i + 1`、`k = i` から始める
2. `s[k]` と `s[j]` を比べる
   - `s[k] < s[j]`: 後ろの方が大きいので、`[i, j]` 全体が1つのリンドン語になる。`k = i` に戻し、`j` を進める
   - `s[k] == s[j]`: 周期の繰り返しが続いている。`k` と `j` をともに進める
   - `s[k] > s[j]`: これ以上は延ばせない。ここまでの周期の長さ `p = j − k` ごとに、`[i, ...]` を長さ `p` のリンドン語の繰り返しとして出力し、`i` を進めて分解の残りを探す
3. 文字列の終わりまで1〜2を繰り返す

各文字が比較に使われる回数は高々定数回なので、全体で線形時間になる。

## 特性・トレードオフ

- **線形時間・O(1) 追加メモリ**: 接尾辞配列も作らずに分解が得られる。短く、速く、バグが入りにくい
- **最小巡回シフトへの応用**: 文字列 `s` を2つつなげた `s+s` をリンドン分解し、先頭が `[0, n)` の範囲にある最後の塊の開始位置が、`s` の辞書順で最小の巡回シフトの開始位置になる
- **分解の一意性**: リンドン語は辞書順の弱い降順で並び、その分解は一意。比較順序を変える(アルファベットの順序を入れ替える)と、分解も変わる
- **使いどころ**: 文字列の正規形(巡回等価な文字列を同じ表現にそろえる)、環状DNA配列の比較、接尾辞ソートの前処理、可換でない群のコンビナトリクス

## 実装例

```python
def duval(s):
    """リンドン分解。部分文字列のリストを返す。"""
    n = len(s)
    i = 0
    result = []
    while i < n:
        j, k = i + 1, i
        while j < n and s[k] <= s[j]:
            k = i if s[k] < s[j] else k + 1
            j += 1
        while i <= k:
            result.append(s[i:i + j - k])
            i += j - k
    return result


print(duval("banana"))        # ['b', 'an', 'an', 'a']
print(duval("abababc"))       # ['abababc']
```

```typescript
function duval(s: string): string[] {
  const n = s.length;
  const result: string[] = [];
  let i = 0;
  while (i < n) {
    let j = i + 1;
    let k = i;
    while (j < n && s[k] <= s[j]) {
      k = s[k] < s[j] ? i : k + 1;
      j++;
    }
    while (i <= k) {
      result.push(s.slice(i, i + j - k));
      i += j - k;
    }
  }
  return result;
}

console.log(duval("banana")); // ["b", "an", "an", "a"]
console.log(duval("abababc")); // ["abababc"]
```
