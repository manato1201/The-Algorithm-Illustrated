## 概要

数直線上にいくつもの区間が与えられたとき、**全ての区間を少なくとも1点で貫くように点を打ちたい**。使う点の数をできるだけ少なくするには、どこに何個の点を打てばよいか——という問題(区間点被覆問題、あるいはStabbing Set問題とも呼ばれる)。矢を1本放って複数の風船をまとめて割る「風船割りゲーム」として出題されることも多い。[区間スケジューリング問題](/algorithms/interval-scheduling)と非常によく似た貪欲戦略で、終端の早い区間から処理していくことで、証明付きの最適解がO(n log n)で得られる。

## 仕組み

1. 全ての区間を、**終了時刻(右端)の早い順**にソートする
2. 打った点の集合を空で初期化する
3. ソート順に区間を見ていき、**まだどの点にも貫かれていない**区間が現れたら、その区間の**右端の位置**に新しい点を1つ打つ
4. 新しく打った点が、以降の区間もいくつ貫くかを確認しながら(ソート済みなので、右端がその点以下の区間は全て自動的に貫かれる)、全区間を見終えるまで2〜3を繰り返す
5. 打った点の総数が、区間を全て貫くために必要な最小点数になる

**なぜ「区間の右端」に点を打つのが最善なのか**(交換論法による直感): まだ貫かれていない区間の中で最も早く終わるものを見つけたら、その区間の右端より左側に点を打つ理由はない——右端に打てば、その区間だけでなく、右端の値以下で終わる他の区間も同時に貫ける可能性が最大化されるため、点を"できるだけ右に"押し出しておくことが常に得になる。

## 特性・トレードオフ

- **計算量**: O(n log n)(ソートが支配的)。ソート後は各区間を1回ずつ見るだけの線形走査で済む
- **区間スケジューリング問題との双対的な関係**: [区間スケジューリング問題](/algorithms/interval-scheduling)は「重ならない区間をできるだけ多く選ぶ」問題で、こちらは「全区間を貫く点をできるだけ少なく選ぶ」問題であり、一見異なる目的に見える。しかし実は、**区間点被覆の最小点数は、互いに重ならない区間の最大個数(区間スケジューリング問題の答え)と常に一致する**という美しい双対性(LP双対性の一種)が成り立つ。どちらも「終了時刻でソートして貪欲に処理する」という同じアルゴリズム的発想で解ける点は偶然ではなく、この双対関係の裏返しになっている
- **貪欲法が"証明付きで"最適になる稀有な例**: 「終了時刻の早い区間から処理し、右端に点を打つ」という選択が常に最適解を導くことは、交換論法で厳密に証明できる。これは[区間スケジューリング問題](/algorithms/interval-scheduling)や[ハフマン符号化](/algorithms/huffman-coding)と同じく、貪欲法の正しさを数学的に保証できる稀有な部類の問題であり、マトロイド的な構造(部分構造の独立性)がこの証明可能性の背景にある
- **反例として注意すべき派生問題**: 「各点にコストがあり、コストの合計を最小化したい」「1点で貫ける区間の本数に上限がある」といった制約が加わると、単純な貪欲法では最適性が崩れ、動的計画法や線形計画法が必要になる。「点の個数」を素朴に最小化する今回の設定でのみ、この単純な貪欲法がそのまま最適に機能する
- **使いどころ**: 監視カメラやセンサーの最小設置数の決定(各センサーがカバーできる区間の集合を最小個数で覆う)、放送・通信設備の中継局配置、ゲームの「1本の矢で複数の的をまとめて倒す」判定処理、ジョブに締切区間があるときの検査タイミングの最小化など

## 実装例

```python
def min_points_to_stab(intervals: list[tuple[int, int]]) -> list[int]:
    sorted_intervals = sorted(intervals, key=lambda p: p[1])
    points: list[int] = []
    last_point = float("-inf")

    for start, end in sorted_intervals:
        if start > last_point:
            last_point = end
            points.append(last_point)

    return points
```

```typescript
type Interval = [number, number];

function minPointsToStab(intervals: Interval[]): number[] {
  const sorted = [...intervals].sort((a, b) => a[1] - b[1]);
  const points: number[] = [];
  let lastPoint = -Infinity;

  for (const [start, end] of sorted) {
    if (start > lastPoint) {
      lastPoint = end;
      points.push(lastPoint);
    }
  }

  return points;
}
```
