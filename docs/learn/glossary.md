# 用語集

| 用語 | 意味 |
|---|---|
| **記事** | `content/algorithms/<id>.md` の 1 件。説明・実装例・分類を持つ |
| **frontmatter** | 記事の先頭の構造化データ(`name`・`category`・`subcategory`・`complexity`・`summary`) |
| **`CATEGORY_TAXONOMY`** | カテゴリ → サブカテゴリの分類表。唯一の情報源 |
| **フレーム(コマ)** | 可視化の 1 コマ。配列(または状態)・ハイライト・説明 |
| **ステップ列** | フレームの配列。アルゴリズムの実行を、1 コマずつ記録したもの |
| **可視化(visualizer)** | ステップ列を作る関数と、それを描く部品 |
| **レジストリ(登録表)** | `id → 関数` の表(`SORT_VISUALIZERS` など)。`id in 表` で対応を判定 |
| **`hasVisualizer`** | 「この id に可視化があるか」を返す関数 |
| **Web Worker** | 画面とは別のスレッドで動く処理。ステップ列の生成を任せる |
| **状態色** | `idle`・`comparing`・`swapping`・`pivot`・`settled`。機能的な意味を持つ |
| **発光(グロー)** | 注目を示す光。確定と比較中だけ(`shouldGlow`) |
| **擬似コード** | 言語に依存しない手順の記述。再生中の現在行を光らせる |
| **独立した検証** | 別の方法で作った正解(標準の関数・総当たり・既知の値)との突き合わせ |
| **不変条件(性質)** | 常に成り立つ性質(例: 最後のコマが整列している) |
| **brute-force(総当たり)** | 全部を試して答えを出す単純な方法。検証の正解に使う |
| **Atlas** | 年表。アルゴリズムが生まれた目的と出典を持つ |
| **依存の地図** | 記事本文のリンクから読み取った、記事どうしのつながり |
| **Edge Function** | Vercel の、端に近い場所で動く関数。更新情報の RSS を中継する |
| **three.js** | ブラウザで 3D を描くライブラリ。3 次元の可視化だけで読み込む |
| **pixi.js** | WebGL の 2D 描画ライブラリ。確定時の粒子の演出に使う |
| **静的生成** | ビルド時にページを作っておく方式 |
