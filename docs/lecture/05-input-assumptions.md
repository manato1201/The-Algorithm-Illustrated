# 第 5 回 入力の前提と乱数

> 所要時間の目安: 2.5 時間 / 前提: 第 1〜4 回

## この回のゴール

- 可視化の関数が、**どんな入力を前提にしているか**を、自分で調べられる。
- 前提を外れた入力で、**何が起きるか**を確かめられる。
- `Math.random` を使う可視化の**扱い方**を説明できる。

## 1. 入力は固定のデモ

アプリは、**固定のデモ配列**(例: 探索なら `SEARCH_ARRAY`)で可視化を動かします。利用者が任意の入力を入れる画面は、基本的にありません。だから、関数が**すべての入力**を想定していなくても、画面では問題が出ません。**ただし、前提は、書いておくべき**です(コードを再利用するとき・入力を自由にするとき、事故になる)。

## 2. 前提を外れた入力

```javascript
// 実行できる
(async () => {
  const { SORT_VISUALIZERS: V } = await import("./src/lib/sort-visualizers.ts");
  const sorted = (a) => JSON.stringify([...a].sort((x, y) => x - y));
  const run = (id, input) => {
    try {
      const frames = V[id](input);
      const last = frames[frames.length - 1].array;
      return JSON.stringify(last) === sorted(input) ? "正しい" : `誤り(${JSON.stringify(last)})`;
    } catch (e) {
      return `例外(${e.message})`;
    }
  };
  console.log("バブルソート [] :", run("bubble-sort", []));
  console.log("バブルソート [-1,3,2] :", run("bubble-sort", [-1, 3, 2]));
  console.log("基数ソート [] :", run("radix-sort", []));
  console.log("基数ソート [-1,3,2] :", run("radix-sort", [-1, 3, 2]));
  console.log("計数ソート [] :", run("counting-sort", []));
  console.log("計数ソート [-1,3,2] :", run("counting-sort", [-1, 3, 2]));
  console.log("計数ソート [3,3,3] :", run("counting-sort", [3, 3, 3]));
})();
```

```text
# 出力
バブルソート [] : 正しい
バブルソート [-1,3,2] : 正しい
基数ソート [] : 正しい
基数ソート [-1,3,2] : 誤り([2,3,0])
計数ソート [] : 例外(Invalid array length)
計数ソート [-1,3,2] : 正しい
計数ソート [3,3,3] : 正しい
```

- **比較ベース**のソートは、空でも負の数でも正しい。
- **基数ソート**は、負の数で**誤った結果**(要素が欠ける)になる(桁ごとの分配が、非負の整数を前提にしているため)。
- **計数ソート**は、空の配列で**例外**(最大値が無いので、配列の長さが不正になる)。負の数は扱える。
- **コードは直していません**(読んで見つけたことを記録する方針)。入力を自由にするなら、**前提の検査**(空・負の数・非整数)を足し、検査で落ちる入力を**テストに入れる**。

## 確認問題

1. 画面では問題が出ないのに、入力の前提を書いておくべきなのは、なぜですか。
2. 基数ソートが、負の数で誤った結果になるのは、なぜですか。
3. 乱数を使う可視化に、再現できる検査が書きにくいのは、なぜですか。

## 解答

1. コードを再利用したり、入力を自由にしたりしたとき、前提の外れが事故になるから。
2. 桁ごとの分配が、非負の整数を前提にしていて、負の数を正しく扱えないから。
3. 実行ごとに結果(コマ)が変わり、同じ入力で同じ出力を期待する検査が使えないから。

## まとめ

- 入力は固定のデモなので、前提の外れは画面には出ない。**でも、前提は書いて、検査する**。
- 基数ソートは負の数、計数ソートは空の配列が、前提の外れ。
- 乱数は**シードで再現できる**形に。これで講義は終わり。続きは [学習資料](../learn/index.md)。
